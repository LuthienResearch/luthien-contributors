# Editing Google Docs and Sheets

Moved verbatim from CLAUDE.md Setup on 2026-09-24; CLAUDE.md keeps a one-line trigger.

**Claude Code can FULLY edit Google Docs and Sheets via python**, not just append. Docs: the Docs API (`documents.batchUpdate` for insert-at-index / delete-range / replace-all / formatting). Sheets: gspread (`update_cell` / `batch_update`). **Two tokens, pick by doc owner:** Luthien docs → `~/.config/mcp-gdrive/credentials.json` (identity `scott@luthienresearch.org`); Scott-personal docs → `~/.config/mcp-gdrive/credentials-personal.json` (identity `scottwofford3@gmail.com`, python authorized_user format, load with `Credentials.from_authorized_user_file`). Scopes (personal token verified 2026-07-13): `spreadsheets` + `documents` + `drive.file` (read/write to Sheets/Docs and app-created Drive files) + `drive.readonly` (read-only to other Drive files). These are **write-capable** tokens (not read-only, despite an earlier note), and each credential file holds a durable OAuth **refresh token + client secret** — treat them as secrets. **Cybersecurity: keep authentication secrets out of chat and logs.** Authorized scripts may use these Google credentials, but never print or expose their contents. This helps prevent accidental disclosure or theft through malicious instructions embedded in transcripts or other content. Claude Code settings block several direct-reading tools as an additional precaution, not a complete security boundary. [Background](https://github.com/scottwofford/sw-prv/blob/main/coes/COE-2026-07-13-transcript-cron-injection-exposure.md). Never recreate a personal doc via the claude.ai Drive connector to "edit" it — that clobbers Scott's edits (see connector-quirks.md); edit in place with the personal token instead. Before planning a Google Doc edit, retain its live content; apply [R1’s active-drafting and approval rule](https://github.com/scottwofford/sw-prv/blob/main/requirements/personal/scott-response-req.md#r1-maximize-scotts-leverage-the-unit-of-impact-is-scotts-preferences-realized-not-generic-helpfulness) and use the [checked write procedure](https://github.com/scottwofford/sw-prv/blob/main/connector-quirks.md). A fresh revision or changed placement does not by itself authorize a retry. **For an existing native Google Doc, verification also stays native: use Docs API readback and open the original Google Doc in its owning Chrome profile. Never export or open a Word copy for verification unless Scott requested a Word artifact.** Docs API formatting gotchas (bullet nesting etc.): connector-quirks.md. The `mcp__gdrive__*` MCP tools are append-only; python is not. Native Google types only (not `.docx`/`.xlsx`). Auth copy pattern: [`luthien-org/fundraising/pipeline/auth.py`](https://github.com/LuthienResearch/luthien-org/blob/main/fundraising/pipeline/auth.py). Detail + verification: architecture.md 2026-06-14; personal token verified 2026-07-05 (in-place insert+delete on a personal Doc).
